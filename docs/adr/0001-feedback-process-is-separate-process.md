# ADR-0001：反馈工具必须是独立进程

- 状态：已接受（冻结，见 IMPLEMENTATION_PLAN.md §2）
- 日期：2026-08-12

## 背景

初版设计中"反馈工具"曾在主进程内以定时器/协程实现，成本低。

## 决策

反馈工具作为**独立进程**运行（`child_process.fork` 或同等跨平台机制），不得与主 Agent 或调度 Agent 运行在同一事件循环中。主进程负责启动、健康检查、优雅关闭与异常重启。

## 后果

- 优点：主进程崩溃不丢信箱；Agent busy 时投递不阻塞主进程事件循环；重启后可从 journal 重放。
- 代价：进程间通信、生命周期管理、孤儿清理复杂度增加（T04、T12 覆盖）。
- 退化为进程内定时器/协程视为违反冻结决策。
