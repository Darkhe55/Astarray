# ADR-0005：仅缓存确定性且无副作用的调用

- 状态：已接受（冻结）
- 日期：2026-08-12

## 背景

缓存需要降低总 token 消耗与调用次数，但错误复用会产生错误结果。

## 决策

仅缓存确定性且无副作用的调用；写操作、时间敏感调用和失败默认 bypass。v0.1 不实现语义缓存（不以模糊语义相似度复用缓存）。缓存键包含：Provider、模型、模式、输入、系统提示词哈希、工具子集哈希、上下文摘要哈希和相关文件指纹。

## 后果

- 命中仅发生在严格等价场景，宁可 miss 不冒险复用（"增加缓存有效率，而非单纯提高命中"）。
- 指标区分 `hit / miss / bypass / stale_reject`。
