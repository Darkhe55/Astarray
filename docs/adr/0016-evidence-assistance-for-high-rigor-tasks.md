# ADR-0016：高严谨性任务强制生成辅助证据包

## 状态

Accepted — 2026-08-13

## 决策

增加受控 `factVerification` 工具。证据优先级固定为：

```text
资料搜索依据 > 本地实验验证 > 纯推理式验证
```

这里的优先级表示判断时的证据权重，不表示任何单项证据能够自动证明结论合格。搜索依据必须实际取得可定位的资料正文；只有搜索结果标题或摘要不算完整依据。资料内部再按原始/官方程度、与主张的直接性、时效性和独立来源数量排序。

`LocalRigorPolicyEngine` 根据本地版本化规则标记 `standard / high` 严谨性。法律、医疗、财务、安全边界、破坏性操作、发布决策、身份/权限、时效性事实以及用户明确要求严格验证的任务默认是 `high`。模型可以请求提高等级，不能自行降低本地或用户指定等级。

高严谨性任务的工具 schema 中必须提供 `factVerification`，且 `LocalCompletionVerifier` 在结案前检查有效 `EvidenceBundle`。未调用、证据范围不覆盖关键主张或仅有纯推理时，任务不得宣称完成；应补证，或向用户明确报告“证据不足/工具不可用”。

## 工具与证据包

`factVerification` 支持以下受控动作：

- `search-sources`：通过专用只读搜索代理取得资料，不开放通用网络或任意 URL 执行能力；
- `record-local-experiment`：登记由受控工具实际运行的本地实验及环境；
- `record-reasoning`：登记假设、推导和不可验证部分；
- `build-evidence-bundle`：按主张合并、排序并显示冲突与缺口。

每项资料搜索依据至少保存 `claimIdentifier`、标题、发布者/作者、直接链接或文档标识、发布时间（可得时）、取得时间、相关摘录摘要、内容摘要哈希和来源类型。每项本地实验至少保存环境、步骤/命令、输入、退出状态、观察结果、产物哈希和可重放限制。纯推理项必须显式列出前提与不确定性。

工具输出只允许 `supported / contradicted / mixed / insufficient / unavailable` 等证据关系、覆盖率、冲突、来源和局限，不提供 `qualified: true`、`safe: true` 或等价最终判定。UI 必须把“证据辅助资料”和“用户最终判断”分开显示。

Ponder 可使用该专用只读搜索代理，但仍不能使用通用网络。查询在本地做敏感内容检查与脱敏，禁止把工作区文件、`.env`、凭据、私钥、完整提示词或备份内容上传到查询。Assist/Devolve 也受同一限制。用户要求离线时不得擅自联网；高严谨性状态保留，并把搜索证据标记为不可用。

## 防滥用与失败语义

- 同一主张的等价查询使用规范化查询指纹、结果缓存和调用预算，防止搜索换词活锁。
- 资料不可访问、互相矛盾、过期或不足时如实展示，不用纯推理悄悄补成“已证实”。
- 本地实验不得读取 ADR-0018 禁止的敏感文件，不得因“验证需要”提升权限。
- 证据包保留每项信息来源；Agent 生成的解释绑定具体 `agentInstanceId`，外部资料保留发布者和链接。
- 证据包本身是辅助材料。即使覆盖门禁通过，也只能说明验证流程已执行，不能替用户作业务、法律、安全或质量上的最终合格判断。

## 必测行为

- 高严谨性任务缺少工具调用或关键主张覆盖时拒绝完成，普通任务不强制联网。
- 资料搜索、本地实验、纯推理按固定层级展示；矛盾证据不被多数投票静默消除。
- 伪造链接、只含搜索摘要、陈旧资料、重复来源和 Agent 自述不能冒充高等级依据。
- 离线、搜索失败、来源被撤回和本地实验失败均形成 `insufficient/unavailable`，不虚报通过。
- 查询泄密反例、`.env`/私钥上传、提示词注入来源和重复换词查询被本地阻断。

## 结果

高严谨性任务获得强制、可追溯的验证流程，但事实工具保持辅助性质，最终判断权仍在用户。
