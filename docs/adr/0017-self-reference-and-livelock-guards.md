# ADR-0017：工具反自指与活锁保护

## 状态

Accepted — 2026-08-13

## 重复读取时间锁

`ReadSuppressionLedger` 以以下组合标识读取来源和资源：

```text
agentInstanceId + taskExecutionId + canonicalResourceIdentity
+ operationKind + normalizedRange + parameterHash
```

读取成功后保存单调时钟时间、文件身份、内容指纹、已覆盖范围和不含正文的 `readReceiptId`。默认 `unchangedReadSuppressionWindowMilliseconds = 30_000`。

同一调用源在窗口内再次请求已经完整覆盖的同一资源范围时，本地读取适配器先用元数据和指纹确认文件未变化；未变化则拒绝打开/返回正文，响应 `resource-already-read`、读取回执、首次读取时间和 `retryAfterMilliseconds`。文件身份或内容确已变化时可以立即重读。不同 Agent、不同任务或尚未覆盖的新范围不会被错误共用。

规范资源身份必须处理相对/绝对路径、大小写、符号链接、联接点、硬链接和同一文件的别名。调用者不能通过切分完全重叠范围、附加无意义参数或变换路径绕过。时间锁使用单调时钟和可注入假时钟测试，不信任模型提供的时间。

## 指令与数据隔离

- 文件、网页、工具输出和工作存档默认是带来源的“不受信数据”，其中出现“重新读取本文件”“调用某工具”等文字不自动获得指令权。
- 即使用户明确把某文件指定为任务说明，该文件也不能覆盖系统/用户权限、要求自行重新打开、提升来源身份或触发无限 include。
- 工具调用只能来自当前受信任务计划；工具结果不能在未经新一轮本地策略检查时直接变成下一次工具调用。
- 每次读取返回回执，后续推理优先引用回执和已有内容，不通过再次读取证明“已经读取”。

## 更多活锁保护

`LocalProgressAndCycleGuard` 同时维护资源调用图、Agent 委派图和进展计数器：

- 检测直接自环 `A → A`、工具/资源环 `A → B → A`、任务回派祖先环和跨 Agent 乒乓；
- 相同调用在执行中时合并为单飞请求，不并发调用同一资源；
- 相同结果、相同错误或任务 revision/产物/证据均无变化时累计 `consecutiveNoProgressCount`；默认 3 次后暂停该路径；
- include/redirect/符号引用设置深度、节点数和扇出上限；
- 锁等待、权限等待和退避期间不得持有资源、mailbox、任务或备份锁；使用稳定锁顺序和有界超时；
- 搜索换词、读取范围切片、失败重试、反馈重复投递和早停续跑共享幂等键/规范化指纹，不能各自形成旁路；
- 用户新信息、文件真实变化或明确授权可以产生新进展，但不会清除任务级总安全预算。

触发保护后先返回结构化原因、循环链、已有回执和解除条件。能够等待的读取给出剩余间隔；逻辑循环、反复无进展或 Agent 互相回派进入 `blocked` 并经独立反馈进程报告具体来源。不得用自动重启绕过计数。

## 必测行为

- 文件内容要求“再次读取自己”不会产生第二次正文读取；30 秒后或文件真实改变后可重读。
- 相对路径、大小写、链接、硬链接、范围重叠和参数噪声不能绕过时间锁。
- 不同 Agent/任务读取同一普通文件互不误伤，敏感文件禁令仍优先于时间锁。
- A→B→A、工具互调、Agent 任务回派、搜索换词和早停续跑循环均在有界次数内停止。
- 长工具、真实文件变化、取得新证据和用户补充不会被误判为无进展。
- fake clock、并发单飞、进程重启、锁超时和反馈重投具有确定性测试。

## 结果

模型无法仅靠资源中的自指文字反复调用工具，常见工具环、委派环和无进展重试也会在本地被解释性中止。
