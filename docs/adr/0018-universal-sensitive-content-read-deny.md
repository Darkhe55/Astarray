# ADR-0018：所有模式禁止模型读取本地敏感内容

## 状态

Accepted — 2026-08-13

## 决策

在 Ponder、Assist、Devolve 三种模式下，所有模型可见工具、通用适配器、插件、MCP、shell、事实验证工具和 Agent 工作存档都禁止读取或返回本地敏感内容。模式升级、会话授权、任务来源、工具类别、用户“记住授权”和模型声明均不能放行。

本地 `SensitiveContentAccessPolicy` 至少拒绝：

- basename 为 `.env`、以 `.env.` 开头或以 `.env` 结尾的文件；该匹配按平台安全大小写折叠执行，因此 `.ENV`、`.Env.Local` 等变体也拒绝；
- `.npmrc`、`.pypirc`、`.netrc`、`.git-credentials`、Docker/云平台凭据、kubeconfig 和同类凭据库；
- SSH/PGP 私钥，`id_rsa`、`id_ed25519`、`*.key`、`*.pem`、`*.p12`、`*.pfx` 等私钥/证书容器；
- 本地密钥链、操作系统凭据存储、Astarray 内部能力令牌和备份恢复凭据；
- 配置中由管理员扩展的规范敏感路径和名称。

已知敏感路径在打开文件前按规范路径、realpath、链接链、硬链接身份和平台大小写规则拒绝。对名称正常但内容疑似包含凭据的文件，只允许本地可信 DLP 扫描器流式检查；一旦命中，丢弃整个模型可见结果，不返回部分正文、匹配片段或秘密摘要。扫描器不是模型工具，不能把内容写入日志、缓存、证据包、错误或反馈。

目录列举和搜索必须过滤敏感条目及其内容命中；错误只返回稳定代码 `sensitive-content-read-denied` 和规则类别，不确认秘密值。Git diff/log/show、压缩包、符号链接、硬链接、编码/二进制转换、base64、OCR、备份恢复和事实验证上传都必须经过相同策略，防止旁路。

程序自身可以通过专用配置装载器在最小权限进程内使用运行必需的环境变量或凭据，但原值不能进入模型、普通工具、Agent 存档或 UI。安全扫描属于本地可信计算边界，不等于允许模型读取。

## 优先级与失败语义

- 敏感禁读先于 Ponder 读取时间锁、Assist 授权和 Devolve 免询问策略执行。
- 被拒绝读取不创建包含内容的自动备份或读取缓存；安全审计只记录脱敏元数据。
- 任何无法确定是否敏感、DLP 扫描失败、路径身份不确定或编码无法安全检查的情况 fail-closed。
- 用户若确需使用某个值，应在模型外完成操作；本版本不提供逐次例外入口。

## 必测行为

- 三种模式以及所有工具通道均拒绝 `.env`、`.env.local`、`service.env`、私钥和凭据库。
- 大小写变体、相对/绝对路径、UNC、链接/联接点、硬链接、Git 历史、压缩包、编码和重命名伪装不能绕过。
- list/search/glob 不泄露敏感内容；日志、错误、反馈、证据包、缓存和存档均无秘密字节。
- Devolve、用户会话授权、伪造 descriptor 和插件自报安全不能放行。
- 普通非敏感配置文件仍可按模式策略读取，避免把全部配置读取误杀。

## 结果

本地秘密对模型形成不可配置的全模式禁止边界，同时保留程序自身在最小权限隔离中使用必要凭据的能力。
