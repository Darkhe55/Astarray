# ADR-0029：Agent 工作集与默认 10 文件读取预算

- 状态：已接受，待实现
- 日期：2026-08-24
- 决策范围：默认 10 文件工作集、独立治理文档预算、来源计数、范围化扩展边界
- 对应任务：T07E

## 背景

每个具体 Agent 每次任务激活若无限读取项目文件，会迅速耗尽上下文。需要在本地建立可审计、跨重启保持的工作集预算：默认不超过 10 个不同项目内容文件，达到预算后压缩、淘汰或拆分侦察 Agent，而不是继续注入原文。

## 决策

### 1. 默认工作集预算

- 默认 `maximumDistinctProjectContentFilesPerAgentActivation = 10`；默认 `workingSetWarningThresholdFileCount = 8`。
- 请求第 11 个不同内容文件时本地返回 `working-set-budget-reached`，不得先读取正文再决定。
- "10 个文件"是效率预算，不是安全不变量：合法大任务经受控扩展或多个独立侦察 Agent 完成；`.env`/私钥/凭据/备份仍由强制安全策略无条件拒绝。

### 2. 计数与身份

- 预算按规范资源身份计数：相对/绝对路径、大小写、符号链接、联接点、硬链接、范围切片不能重复占槽或绕过。
- 同一文件重读不增加文件数，但继续消耗字节/token/反自指/总调用预算；文件真实变化后重读仍占原槽，旧摘要标 stale。
- 新建 Agent、模型/Provider 切换、早停续跑、进程重启与 handoff 不能清零任务链累计预算。
- 每个 Agent 保持自己的 10 文件活动工作集；任务链保存全部 Agent 的累计来源清单（防无限创建 Agent 隐藏总读取量）。

### 3. 占用槽位的操作

- 列目录/文件名、stat、大小、时间、Git 状态：不占内容文件槽（计独立枚举预算）。
- 读取任意正文范围、搜索返回源码片段、Git diff/show/blame 返回内容、归档/拼接/聚合摘要（按 manifest 原文件分别计数）、OCR/图片/PDF/二进制解析：每个来源文件占 1 槽。
- 强制治理文档（AGENTS/架构/实施计划）用独立治理文档预算，不挤占 10 个项目工作文件槽。
- 敏感文件在预算判断前直接拒绝，不登记正文或指纹。
- 聚合结果没有可信来源 manifest 时 fail-closed。

### 4. 多维预算

- 同时记录：不同项目内容文件数、模型可见项目内容字节数、估算/Provider token 数、枚举/搜索/Git/附件数量、活动工作集与任务链累计来源集合。
- 字节/token 阈值由任务用途、模型上下文与用户配置共同解析；任何阈值变化用完整单位命名、版本化配置与审计。

### 5. 预算达到后的处理

- 达到 8 文件 → 本地提醒调度者检查相关性；
- 达到 10 文件并请求新文件 → 拒绝正文读取 → 淘汰不再需要的活动引用或生成摘要 → 拆分严格子任务给侦察 Agent → 无法拆分时申请 `ReadBudgetExpansionGrant`。
- ExpansionGrant 绑定具体 Agent、任务链、当前预算 revision、新增文件数、允许路径/用途、理由、期限与发布者来源；次级只能在用户配置允许范围内批准；扩展不是文件读取权限，也不放宽敏感禁读、Ponder 只读边界或工作区范围。

## 完成条件

- 同一 Agent 读 10 个文件成功，第 11 个在读前拒绝；别名/链接/搜索/Git/聚合旁路反例全通过。
- 重启/续跑/handoff 不清零任务链累计；多个侦察 Agent 各 ≤10 文件，次级只收摘要。
- 扩展 grant 参数/路径/任务/Agent/期限/revision 变化后失效；项目文字不能自批扩展。
- Ponder/Assist/Devolve/自定义模式下效率预算一致记录，实际可读能力由各自权限策略决定。
