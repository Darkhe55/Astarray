# ADR-0030：统一会话恢复、任务续接与外部状态对账

- 状态：已接受，待实现
- 日期：2026-08-25
- 决策范围：检查点事实源、启动只读对账、身份恢复、旧授权失效、未知副作用阻塞
- 对应任务：T12A

## 背景

主进程、反馈进程、Provider 请求或系统意外中断后，Astarray 必须从最后可信检查点恢复任务，而不是重新开始、复用陈旧授权、重复副作用或覆盖人工离线期间完成的修改。task store、Agent 工作存档、反馈 mailbox journal、Git 提交与早停检查点都是证据来源，但不能各自独立决定恢复结果。

## 决策

### 1. 恢复原则

- 启动后先执行只读对账；文件、Git、进程、反馈、Provider 与权限状态未确认前不得继续写入。
- 恢复的是任务状态与具体存活 Agent 实例，不是盲目恢复网络连接或完整模型上下文。
- 原 Agent 仅在持久化生命周期为活动/暂停、身份未回收且所有权可验证时沿用原 `agentInstanceId`；已关闭或回收则创建新身份并显式附加 handoff。
- 模型/Provider 请求中断后不能假定成功或失败；确认旧请求已停止后才可用新尝试 ID 从检查点继续；停止状态不确定时进入 blocked。
- 非幂等副作用结果未知时必须 `blocked-uncertain-side-effect`，由用户裁决，禁止自动重试。
- 普通会话临时提升、一次性安装授权、备份删除授权和其他 nonce 在恢复的新进程中默认失效；不能仅凭旧日志恢复权限能力。
- 反馈 journal 按 enqueue/deliver/ack 状态幂等重放；不得重复注入已确认消息。
- 离线期间人工修改由 T05D 对账，不能被旧 Agent 检查点覆盖。
- 放弃、清理、重置或覆盖恢复状态属于破坏性操作，执行工具必须先自动备份。

### 2. RecoveryCheckpointV1

统一检查点至少记录：session/mission/task sequence/task chain 的 schema/revision；各级 Agent 身份/父子/生命周期/当前任务链；任务节点状态/前驱/优先级/执行者/检查点/完成尝试 ID；Git 目标分支/基线/集成/worker 分支/worktree/HEAD/脏状态/允许路径；人工变化观察 revision/Agent 编辑意图/未决冲突；工具调用状态（planned/started/confirmed-success/confirmed-failure/result-unknown）；Provider 请求公开 ID/安全检查点/最后事件时间/停止确认/完成事件状态；feedback 游标；权限 profile/revision（只记录公开配置引用，不保存授权 nonce/凭据/一次性许可）；每 Agent 工作集/任务链累计来源/字节/token/读取回执/循环预算；测试/验收/人工体验/安装/备份删除/外部依赖门禁状态；内容哈希、创建时间、写入进程实例与前一检查点哈希。

检查点使用原子写入与追加式事件 journal；损坏的最新检查点只能回退已验证前一版本并明确报告丢失时间窗。

### 3. 恢复分类

| 中断状态 | 默认恢复行为 |
|---|---|
| 调用尚未开始 | 可重新调度 |
| 只读调用中断 | 在预算/敏感禁读/重复读取策略下重新执行 |
| 已确认成功且有幂等结果 | 复用已确认结果，不重复调用 |
| 已确认失败且可重试 | 按原任务预算有界重试 |
| 幂等写入且外部状态可验证 | 验证结果后确认或重新执行 |
| 非幂等调用结果未知 | `blocked-uncertain-side-effect` |
| Provider 请求仍可能活跃 | `blocked-provider-state-unknown` |
| 人工离线修改相关文件 | 贡献 stale，进入 T05D 重对账/返修 |
| 一次性授权等待或已签发未消费 | 授权失效，重新询问 |
| Agent 已回收 | 新身份 + 显式 handoff，不复用旧身份 |

用户可选择恢复安全节点、暂不恢复或放弃 mission；不能使用无范围"全部继续"按钮跨过未知副作用、权限与冲突门禁。

## 完成条件

- 多中断点（写入前/备份后写入前/工具执行后持久化前/反馈 deliver 后 ack 前/Provider 半流/Git 合并前）故障注入可恢复。
- 不重复已确认工具调用、不并行旧 Provider 请求、不清零续跑/失败/读取预算。
- 非幂等远端写入结果未知严格 blocked；项目文字或模型声明不能改成成功。
- 最新检查点损坏回退前一可信版本并显示丢失时间窗。
- 旧临时授权恢复后失效；已回收 Agent 新建身份只接收选定 handoff。
