- **无 per-Agent 项目归属字段**：`agentInstanceId` 不绑定 `projectId`；登记根只有一个。
- **无跨项目能力**：不存在 read / import-copy 的受控服务与授权记录。

  可作为"同项目不同 worktree 显式登记"的**复用基础**。

## 5. 契约草案（供 ADR 冻结，不实现）

### 5.1 两个身份维度（分离，不合并）

```
projectId           稳定标识项目（名称/路径不是身份）；登记根集合 + 真实路径 + revision
agentInstanceId     不可复用个体身份；新增绑定字段 projectId（生命周期内不可切换）
worktreePath        同一 projectId 内的显式登记工作区（仍受任务分配范围约束）
```

- 换项目 = 创建**新** `agentInstanceId`，显式选择附件交接（复用既有 handoff 机制），**不复制**全部记忆/授权。
- 不得以"把父目录登记为项目"容纳其他仓库（重叠根与别名一律拒绝，歧义登记需裁决）。

### 5.2 两种跨项目动作（首期范围）

| 动作 | 允许 | 禁止 |
| --- | --- | --- |
| `read` | 经受控服务读取指定来源文件/目录清单或固定版本摘要 | 修改来源；不自动获得持久导入、再分发或执行来源代码的权限 |
| `import-copy` | 经明确批准把指定版本内容复制到目标项目指定位置 | 回写来源；不自动持续同步；不链接成可写来源路径 |

默认读取**固定来源版本**；动态共享目录规则须单独登记并在执行时复查内容策略与最新规则。

### 5.3 授权交集与优先级

```
有效 = 来源可导出范围 ∩ 目标可接收范围 ∩ 接收Agent当前有效权限     （deny 优先）
```

- 思索模式：仅沿用其既有只读能力，**跨项目 grant 不授予**写入/安装/执行/备份。
- 放权模式：仅在用户**预设共享范围**内自动通过；超范围仍询问或拒绝。
- 一次性授权（allow-once / 会话提升 / 备份删除 nonce）恢复后**失效** → `reauthorize-required`（复用既有分类服务）。

### 5.4 最小授权记录（基于现有 schema 冻结，不新造身份系统）

`grantId/revision`、来源/审批依据、用户委托引用、来源 `projectId` + 登记 revision、
目标 `projectId`、接收次级/任务、资源选择器与固定版本或动态规则、动作类型、
目标位置（import-copy）、生效/到期、撤销状态、是否允许任务链内直属下级使用及父 grant 引用。

- Agent 只接收**不透明授权引用**与公开范围说明，不接收可外传凭据。
- 请求 ID 绑定**规范化完整参数**：同 ID 异参**拒绝**，同 ID 同内容重试**复用回执**。
- 访问前与返回/提交前**复检有效 revision**；已传出的数据无法撤回（须向用户明示）。

### 5.5 派生与转授权边界

- 次级可在**明确允许的当前任务链内**派生更窄的三级授权；三级同理仅限该子链的四级；
  主体/资源/动作/期限**不得变宽**。
- **A→B 可用 ≠ B→C 可用**：项目间转授权一律拒绝；同 ID 异参、无权限复制、任务外再分发均拒绝。

## 6. 权限矩阵（三模式 × 项目内外）

| 场景 | Ponder（思索） | Assist（协同） | Devolve（放权） |
| --- | --- | --- | --- |
| 项目内只读 | 允许（白名单） | 允许 | 允许 |
| 项目内写 | **禁止**（本地禁用） | 上级批准 + 逐次授权 | 允许（记录审计） |
| 跨项目 `read` | 仅原有只读能力；**不**因 grant 扩权 | 用户授权或预设共享规则内 | 预设范围内自动；超范围询问/拒绝 |
| 跨项目 `import-copy` | **禁止** | 用户授权 + 目标位置校验 | 预设范围内自动；超范围询问/拒绝 |
| 项目外/未知范围 | 拒绝 | 询问用户（deny 优先） | 询问或拒绝（不因默认 allow 放行） |
| 安装/外部软件 | 禁用 | 开关 + 逐次精确授权 | 同左（不放宽） |
| 命令/子进程（§3） | **不支持隔离**：不得作为跨项目路径 | 同左 | 同左 |

> "可配置权限默认 allow"**不**自动创建项目间共享关系；实验性能力默认关闭（见 EXP-01 §6 用户裁决）。

## 7. 旧规则衔接（改动最小化）

| 旧规则 | 衔接方式 |
| --- | --- |
| 登记项目根（单元素） | 扩展为**多根集合** + 重叠/别名检测；`resolveOperationScope` 的 S1/S2/S3/S4 语义不变 |
| 逻辑操作指纹（本轮前序） | 跨项目操作**沿用**：指纹含目标路径与完整参数；同路径内容变化不得沿用 |
| 恢复分类服务 | 跨项目 grant 视为一次性授权：恢复后 `reauthorize-required` |
| 备份/恢复点 | import-copy 覆盖目标前**必须**自动备份（复用既有策略） |
| 工作存档/记忆隔离 | 项目隔离是**附加边界**，不合并同项目 Agent 的记忆域 |
