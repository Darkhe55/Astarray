## 3. 已知陷阱（务必先读，本会话反复踩到）

1. **JSDoc 陷阱**：注释里出现 `*/`（如写 `agent-memory/*/xxx`）会**提前关闭注释块** ⇒ 整文件解析失败（`TS1434/TS1068/TS1160`）。
2. **模板字符串被反引号提前终止**：页面 HTML 由 JS 模板字符串承载时，`<script>` 内的注释里**不得出现反引号**（`` `x` ``）⇒ `TS1005/TS1443`。**同类陷阱**。
3. **CRLF**：仓库文件多为 CRLF；用文本锚点做替换前**先规范化为 LF**，否则匹配失败。
4. **PowerShell 引号/转义**：本会话**三次**因 PowerShell 的引号、`}` 未转义、`Trim("n")` 掉反引号而**脚本未执行或写坏文件**。**优先用 `edit` 工具**，不要写多行 PowerShell 替换脚本。
5. **提交信息**：多行 `-m` 会被 PowerShell 误解析（把中文引号内容**当成文件路径**）⇒ 用 `git commit -F <文件>`。
6. **`{...obj}` 丢原型方法**：门面方法在**原型**上，对象展开只复制自有属性（会丢 `subscribe`）⇒ 用 `Object.assign` 或显式转发。
7. **覆盖率贴线**：四维门槛 **85**；本会话实测分支 **85.00 → 85.02**，**余量极小**。负载敏感测试一失败，其覆盖分支不计入 ⇒ 覆盖率掉 ~0.2% 并让门禁一起红（见 `docs/reports/COVERAGE_FLAKE_COUPLING_CORRECTION_2026-10-11.md`）。**`check` 首跑偶发 1 failed，复跑即可确认；不得放宽断言**。
8. **CLI 由 `dist/` 驱动**：改 `src` 后**必须 `npm run build`** 才能跑 `verify:*`、打包验收与 `spawn dist/cli.js` 的测试。
9. **`run` 子命令没有 `--state-directory`**；`cwd` 才是决定状态目录/工作区的地方。
10. **mock 运行时不会请求受限工具** ⇒ 权限询问路径**无法用 mock 触发**；须用**假 Provider + `spawn` CLI**（见 `authorization-retry-closure.test.ts` 手法）。
11. **暂存纪律**：只 `git add` 自己的文件；提交前用 `git diff --cached --name-only` 确认**不含 `README.md`**。
12. **推送**：`Connection reset by 20.205.243.166 port 22` 频发；本会话最多**8 次**重试才成功 ⇒ 用**有界重试 + sleep**。
