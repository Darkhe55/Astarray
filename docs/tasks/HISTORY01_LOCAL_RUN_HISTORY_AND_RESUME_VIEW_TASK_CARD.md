# HISTORY-01：本地运行历史与恢复后回溯界面

日期：2026-10-01；状态 pending，仅设计布置，未实施/验收。

## 1. 目标与范围

用户在 resume 后能够查看以前的指令、决策说明、工具调用链、产物、错误和恢复过程。历史在本地持续保存；是否显示只影响界面，不影响保存。复用个体存档、反馈日志、任务/工具回执、T12A恢复、SUM摘要、OBS诊断及SMART指令记录，不新建竞争事实源。

不把历史查看等同于再次执行，也不把整个历史重新注入模型。用户查看和 Agent 读取是两种独立授权路径，用户界面能够汇总获准查看的个体记录，不意味着 Agent 可以读取同级记忆。

“思维链”界面统一命名为“过程说明”：仅展示模型或 Provider 明确提供给应用且允许保存展示的解释、计划和决策摘要，以及工具产生的客观执行记录。不要求、不推测、不生成未公开的内部思维链；不可展示的内部状态、加密推理数据或恢复令牌不渲染为文本。没有过程说明时写“该运行未提供过程说明”，不是空白假装完整。

首期范围为运行记录、文本/结构化工具输出、差异和已存在产物链接；多媒体使用已有预览，不新增通用媒体编辑器。

## 2. 必须保存的历史

| 类别 | 最小内容 |
|---|---|
| 用户指导 | 原始允许保存的消息、来源、指令ID/revision、队列/引导/智能状态、追加/修订及时间 |
| Agent处理 | 具体agentInstanceId、层级/职责、模型及非敏感有效配置快照、公开答复和过程说明 |
| 工具调用 | 调用ID、父调用/所属任务、operationId/attemptId、安全参数视图、开始/结束、耗时、退出/错误、可保存输出及产物引用 |
| 协作链 | 派发、签收、澄清、附件引用、汇报、验收结果与来源；上级摘要不能替换原始回执 |
| 控制事件 | 授权结论的公开元数据、暂停原因、取消、早停、重试、模型切换、配置版本、窗口补位、工作时段 |
| 恢复事件 | 检查点、上次中断位置、未知副作用、resume尝试、对账结果、继续/阻塞结论 |
| 产物与资源 | 文件/提交版本、差异引用、测试/验收引用、用量来源；不重复复制所有项目文件 |

事件带会话、任务、具体来源、稳定ID、持久序号、时间、schema版本。跨进程因果关联优先使用父事件和回执，不依赖墙上时钟简单排序。重试保留为不同attempt，不能被去重成一个成功调用。

## 3. 保存、恢复与完整性

- 关键事件追加持久化，流式文本按有界分块刷新而非每token落盘；启动和副作用意图按现有可靠性契约先记录，结束/取消有最终回执。记录明确的已持久游标，突发崩溃时未落盘尾部标记缺口，不承诺未提交片段零损失。
- 大输出旁置分块保存并建立索引，界面只加载摘要及当前页；允许保存的详情不得因为UI折叠而丢弃。重复正文可用内容寻址去重，但不混淆不同个体访问权限。
- 默认本地保留历史，不因隐藏、resume或上下文压缩删除。历史数量不设静默淘汰上限；允许用户明确归档/删除，遵守备份和专用清理规则，不承诺磁盘无限。
- OBS可选详细性能采样关闭不影响本卡最小运行历史；模型过程说明只有实际提供时保存。高频资源采样不属于必须无限保存的对话原文。
- 写入前清洗凭据、令牌、敏感内容及错误参数，禁止先保存秘密再只在UI遮挡。保留脱敏占位和缺失原因，不把“必须保存”理解为存储凭据或敏感文件正文。
- 存储失败应在本地界面显式告警；必要历史/回执无法持久化时停止派发新的有副作用任务，保留对话/状态/恢复入口，不静默继续制造不可追溯操作。依赖已启动工具按能力收敛，不能一概kill。
- 索引可从合法日志重建，历史摘要非事实源。损坏记录隔离并报告缺口，不默默跳过或把旧历史写成当前状态。旧格式读取采用版本迁移/兼容，破坏性迁移前备份。
- resume读取持久记录后追加新运行段，标出“恢复分界”和对应检查点，保留此前失败/未完成事件，不覆盖。查看任意历史绝不触发工具重放。

## 4. 显示设置与默认布局

显示设置包括：showRunHistory（默认true）、showProcessExplanations（默认false）、showToolCalls（默认true）。详情默认折叠，另提供可见类别过滤和时间范围。关闭总显示开关只隐藏历史区，可随时从“运行历史”入口重新打开；不影响采集，不给清理数据建立快捷旁路。

### GUI布局

- 顶部恢复摘要：上次运行时间、最后可信检查点、已完成/未完成数量、阻塞原因和本次恢复状态。摘要每项可跳至对应证据。
- 左侧导航：运行段/日期、任务及Agent筛选，支持关键词和状态检索；窄窗口收起为抽屉，不固定挤占阅读区。
- 中间时间线：默认按任务分组展示紧凑事件卡，正常工具调用折叠为名称＋安全目标摘要＋状态＋耗时；连续重复事件可分组但显示次数并可展开各attempt。
- 右侧按需详情：工具安全参数、分页输出、错误、证据和产物版本；未选事件时不占位。小屏采用全宽详情/返回，不强制三栏。
- 工具链以可折叠父子列表表达并行、重试和依赖，首期不做复杂全屏关系图。
- 新事件到来时，只有用户位于末尾才自动跟随；用户正在读旧记录时保留滚动位置，显示“有新事件”按钮。筛选和展开状态按用户/会话保存。

### TUI/CLI与内容风格

- TUI默认单列摘要/时间线，键盘切换筛选、展开和详情；窗口缩小时不截掉关键状态。CLI提供分页列表/单事件详情及机器可读格式，复用同一只读查询服务。
- 用户指令、Agent答复、过程说明、工具事实、错误和恢复事件采用明确文本标签区分；状态同时用文字/符号，不只靠颜色。
- 过程说明使用短段落；命令和参数使用等宽块；输出按原行定位分页，长单行可折行/横向滚动，二进制仅显示安全元数据及已有预览入口。
- 不把工具原始日志直接倾倒进对话；失败优先展示错误码、影响和证据链接，模型诊断单独标为推测。超时/结果未知不能画成成功完成。
- 无障碍键盘焦点、屏幕阅读标签和高对比度；可访问性检测不能替代人工体验验收。
- 历史HTML/Markdown、ANSI/终端控制序列、文件链接和媒体均按不可信输入安全渲染：不执行脚本、控制字符或自动加载远端资源。打开文件/导出是显式操作。

## 5. 摘要、检索与性能

复用SUM增量摘要和稳定证据锚点；进入历史页不触发全量模型总结或现场扫描全部会话。旧记录无摘要时先展示确定性事件概览，后台摘要依照设置和用量策略执行。

按游标分页、虚拟列表、延迟展开与分块检索；游标绑定会话/过滤/版本并处理追加，不因新事件重复或漏页。搜索遵循权限和脱敏策略，不搜出隐藏凭据或其他不可见个体记录。

界面载入历史不计入模型上下文；“供Agent参考”是另一个显式动作，经现有附件选择、来源、预算与个体隔离规则执行，不自动导入当前完整历史。

## 6. 实施检查点

| 检查点 | 产出与验收 |
|---|---|
| HISTORY-01-01 | 审计现有日志/个体存档/恢复视图，冻结事件覆盖矩阵、缺口语义、查询接口和只读权限；不得把隐藏推理当必交付 |
| HISTORY-01-02 | 最小历史持久化、输出分块、索引、去重和resume分段；崩溃尾部、磁盘满、坏日志、旧schema、重复反馈及读写并发反例 |
| HISTORY-01-03 | SDK/CLI/TUI/GUI最小历史视图和显示开关；虚拟列表、安全渲染、过滤搜索、锚点和不抢滚动；关闭显示后仍保存 |
| HISTORY-01-04 | 公开tarball恢复回溯、资源测量及人工体验；用户能找到旧指令、失败调用、模型说明和恢复原因，查看不重执行工具/不新增模型上下文 |

每轮一个检查点，预计超过三小时继续拆分。任务登记及共享文件修改由次级在当前检查点收口后协调，不覆盖其他Agent在途改动。

## 7. 必需测试与交付证据

1. 保存→关闭应用→重启/resume→回溯先前运行；再次resume不重复旧事件。
2. 总显示/过程说明/工具显示开关分别关闭后，允许保存的历史仍完整可查询；缺过程说明如实显示。
3. 同级Agent及跨项目访问隔离；用户历史聚合不会扩大模型权限；秘密样本不进入存储或导出。
4. 早停、等待用户、超时未知、取消、重试、乱序结束和多个并行调用均正确显示，历史状态与当前状态分开。
5. 大量事件及超长输出下分页/虚拟化、内存上界、首次可读延迟、搜索耗时和滚动稳定；附规模及设备，不预填指标通过。
6. 恶意HTML/ANSI、远端图片、危险链接及损坏文档不执行、不自动联网。
7. 磁盘满、进程崩溃、损坏索引和数据迁移失败不伪造完整历史；必要回执失败时副作用派发门禁有效。
8. 人工验证键盘导航、窄屏、重启后找回旧工具输出、恢复分界、开关含义；人工待验时自动测试证据单独完成，不能冒充体验已通过。

运行定向测试、npm run check、适用安全与状态机覆盖率；交付npm pack、verify-package.mjs、smoke-install.mjs，经公开入口验证。记录提交/dirty基线、命令退出码、平台、包哈希、截图/人工结论和未满足项。未执行平台保留未验证。阶段验收和本地提交后按常设节奏推送；不提交别人的修改。

首期不建设可编辑历史、自动重演工具、完整推理抓取或复杂可视化拓扑。任务索引与状态表由集成者在可安全编辑时更新；本卡pending不代表功能已上线。
