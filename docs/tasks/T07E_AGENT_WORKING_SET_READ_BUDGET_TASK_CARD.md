# T07E：Agent 工作集与默认10文件读取预算任务卡

> 状态：`in_progress`（T07E-01/02 完成；T07E-03 未开始）  
> 设计日期：2026-08-19  
> 任务来源：用户  
> 优先级层级：0  
> 风险等级：高；必须按检查点单独实现和验收  
> 前驱：`T07B`、`T08A`、`T08C`  
> 后继：`T07D`、`T12A`

> 架构记录：T07E-01 必须新增 ADR-0029，冻结默认10文件工作集、独立治理文档预算、来源计数和范围化扩展边界。

## 1. 目标与结论

为每个具体 Agent 建立本地、可审计、跨重启保持的项目内容工作集预算。默认每次任务激活尽量不让一个 Agent读取超过10个不同项目内容文件；达到预算后优先压缩、淘汰无关文件或拆给侦察 Agent，而不是继续把项目原文塞入同一上下文。

“10个文件”是默认效率预算，不是不可调整的安全不变量。合法大任务可以通过受控扩展或多个各自独立的侦察 Agent完成；`.env`、私钥、凭据、备份等敏感资源仍由强制安全策略无条件拒绝，不能通过扩展预算放行。

## 2. 冻结计数规则

- 默认 `maximumDistinctProjectContentFilesPerAgentActivation = 10`。
- 默认 `workingSetWarningThresholdFileCount = 8`；达到阈值时向调度者返回本地提醒，不自动增加模型调用。
- 请求第11个不同内容文件时，本地返回 `working-set-budget-reached`，不得先读取正文再决定。
- 预算按规范资源身份计数；相对/绝对路径、大小写、符号链接、联接点、硬链接和范围切片不能重复占槽或绕过限制。
- 同一文件重读不增加文件数量，但继续消耗内容字节、估算 token、反自指窗口和任务总调用预算。
- 文件真实变化后重读仍占原槽；旧内容摘要必须标记 stale。
- 新建 Agent、模型切换、Provider切换、早停续跑、进程重启和 handoff 不能清零任务链累计预算。
- 每个 Agent保持自己的10文件活动工作集；任务链另保存所有 Agent 的累计来源清单，防止通过无限创建 Agent隐藏总读取量。
- 大任务允许多个侦察 Agent分别读取不超过10个文件并返回 `PROJECT_CONTEXT_DIGEST_V1`。次级 Agent接收摘要，不直接继承全部原文。

## 3. 哪些操作占用文件槽

| 操作 | 文件槽规则 |
|---|---|
| 只列出文件名或目录项 | 不占内容文件槽；计入独立枚举预算 |
| `stat`、大小、时间、Git状态 | 不占内容文件槽 |
| 读取任意正文范围 | 该规范文件占1个槽 |
| 搜索返回源码片段 | 每个返回正文的来源文件占1个槽 |
| 搜索只返回文件名和匹配数量 | 不占正文槽 |
| Git diff/show/blame 返回文件内容 | 每个内容来源文件占1个槽 |
| 归档、拼接文件或生成聚合摘要 | 按来源 manifest 中的原始文件分别计数，禁止聚合旁路 |
| OCR、图片、PDF或二进制解析 | 每个模型可见内容来源占1个槽，并消耗字节/token预算 |
| 跨 Agent不可变摘要附件 | 接收方不按原文件占槽，但保留完整来源清单、revision、hash和token成本 |
| AGENTS/架构/实施计划等强制治理文档 | 使用独立治理文档预算，不挤占10个项目工作文件槽 |
| 敏感文件 | 在预算判断前直接拒绝，不登记正文或内容指纹 |

聚合结果没有可信来源 manifest 时，必须 fail-closed，不能把几十个文件压成“一个文件”绕过预算。

## 4. 多维预算

文件数量不能单独控制上下文，至少同时记录：

- 不同项目内容文件数量。
- 模型可见项目内容字节数。
- 估算或 Provider 返回的项目内容 token 数。
- 目录枚举、搜索结果、Git内容视图和跨 Agent附件数量。
- 当前活动工作集与任务链累计来源集合。

默认字节/token阈值由任务用途、模型上下文和用户配置共同解析；任何阈值变化使用完整单位命名、版本化配置和审计。不能仅提高文件上限而忽略超大单文件。

## 5. 预算达到后的处理顺序

```text
达到8个文件
  → 本地提醒调度者检查相关性
达到10个文件并请求新文件
  → 拒绝正文读取
  → 优先淘汰不再需要的活动文件引用或生成摘要
  → 仍需要时拆分严格子任务给侦察 Agent
  → 无法拆分时申请范围化 ReadBudgetExpansionGrant
```

`ReadBudgetExpansionGrant` 必须绑定具体 Agent、任务链、当前预算 revision、新增文件数量、允许路径/用途、理由、期限和发布者来源。次级 Agent只能在用户配置允许的扩展范围内批准；用户设置要求人工确认或扩展超过本地上限时进入用户裁决。扩展不是文件读取权限，也不能放宽敏感禁读、Ponder只读边界或工作区范围。

## 6. 检查点序列

| 检查点 | 内容 | 主要验收 |
|---|---|---|
| T07E-01 | 工作集、来源 manifest、预算、扩展 grant 和事件 schema | 计数语义、身份、revision、配置迁移测试 |
| T07E-02 | 规范资源计数与所有模型可见读取通道接入 | 路径别名、链接、搜索、Git、归档、OCR/PDF旁路反例 |
| T07E-03 | 8文件提醒、10文件门禁、字节/token预算和活动集淘汰 | 读前拒绝；不返回第11个文件正文；超大文件受限 |
| T07E-04 | 任务链累计预算、重启/handoff保持和防Agent分裂绕过 | 新身份/续跑不清零；个体预算仍相互隔离 |
| T07E-05 | 侦察拆分、摘要附件和范围化预算扩展 | 多个10文件侦察可工作；次级不接收项目全文 |
| T07E-06 | TUI/CLI 状态、设置、压力测试和 tarball 验收 | 用户可查看原因/来源；大量文件不拖垮界面 |

每轮只执行一个检查点，每个检查点预计不超过3小时；超过时继续拆卡。

## 7. 必测场景

1. 同一 Agent读取10个不同项目文件成功；第11个在打开正文前被拒绝。
2. 同一文件分段、别名、大小写、软/硬链接和重复搜索结果只占一个文件槽，但受反自指与token预算限制。
3. 搜索一次返回11个文件片段时，只能按本地有界策略返回预算内结果，并明确列出未读取来源，不能先全部注入模型。
4. 将11个文件拼成一个临时文件、归档或工具输出不能绕过；来源 manifest 缺失时拒绝。
5. 强制治理文档使用独立预算；普通项目文件仍有完整10个默认槽。
6. `.env`、凭据、私钥和备份读取在预算前拒绝；错误不泄露正文或敏感存在细节。
7. Agent重启、早停续跑、Provider切换或创建接手 Agent后，任务链累计来源不清零。
8. 两个侦察 Agent各读取不超过10个文件，次级只收到有界摘要和来源指纹。
9. 扩展 grant 参数、路径、任务、Agent、期限或revision变化后失效；项目文字不能自批扩展。
10. Ponder、Assist、Devolve和自定义模式下效率预算一致记录，但实际可读能力仍由各自权限策略决定。

## 8. 执行注意事项

- 本任务不能通过减少测试 fixture、隐藏来源或截断审计来满足10文件目标。
- 主 Agent应优先读取次级摘要；次级应优先派侦察 Agent。读取预算不能成为主 Agent直接吞入更多项目文件的理由。
- 预算等待和人工扩展确认时不得持有文件锁、任务领取锁或Provider请求。
- 反馈退避 `pn` 的单次等待上限为3小时；它不是工作集租约期限，也不能用来重置或丢弃累计来源。
- 生产变量/函数名完整可读；所有字节、token、时间和数量变量名称必须显式表达单位或计数含义。
- 每批同时完成实现、反例测试、文档、状态和动态证据；缺少旁路与重启测试不得标记完成。
