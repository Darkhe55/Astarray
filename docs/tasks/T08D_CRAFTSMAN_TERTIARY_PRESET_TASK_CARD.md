# T08D：“工匠”三级 Agent 阶段预设编码任务卡

- 状态：`in_progress`（T08D-01 已完成，T08D-02 未开始）
- 风险：高；必须单批实现和验收
- 架构依据：ADR-0027
- 依赖：T08C、T09、T10、T11
- 后继：T07C、T12

## 1. 目标

实现一个不会在会话开始时注入次级 Agent上下文、仅在本地阶段条件命中后才披露的“工匠”三级 Agent预设。工匠只组合和深度定制当前已经存在且已授权的基础工具，用于形成可复用工作流、方法、模板和安全执行配方。

## 2. 检查点序列

| 检查点 | 内容 | 主要验收 |
|---|---|---|
| T08D-01 | `CraftsmanStageTriggerProfile`、阶段信号、披露事件和 bundle schema | schema 反例、版本迁移、冻结决策测试 |
| T08D-02 | 本地阶段控制器、内置较早/均衡/保守模板、自定义 any/all 规则 | 确定性计时/计数/里程碑/记忆规模/重复指纹测试 |
| T08D-03 | 延迟披露、目标次级隔离、冷却、幂等与崩溃恢复 | 初始 prompt 不含工匠；命中后只通知具体次级一次 |
| T08D-04 | suggest-only、suggest-with-prompt、auto-enqueue-proposal | 自动节点只能 priority tier 1+；提示词不构成授权 |
| T08D-05 | 工匠生命周期、已有工具约束、工作流 bundle 与不同 Agent验收 | 安装/权限/自验反例；真实工作流复用收益证据 |
| T08D-06 | TUI/CLI/GUI 设置、状态、手动披露和 tarball 验收 | 三入口一致；自定义数量不限；隔离安装通过 |

一次只执行一个检查点；一个检查点预计超过约 1,000 行生产代码时，继续拆成契约、领域控制器、持久化、界面/集成节点。前一节点未通过不得开始后继。

## 3. 必测场景

1. 新会话、无阶段命中：没有工匠 Agent实例，次级 prompt、工具说明和可选下级信息不含完整工匠说明。
2. 活跃时间排除暂停、离线、等待授权和纯反馈等待；系统时钟回拨不会提前命中。
3. 任务链只统计通过次级验收门禁的终态；返修、取消和失败不计入。
4. 记忆规模只使用公开索引元数据，不读取正文、`.env`、凭据、备份存储或其他 Agent私有域。
5. 里程碑和重复工作指纹由本地版本化规则生成；不能依赖模型判断阶段。
6. 较早、均衡、保守以及用户自定义 `any/all`、禁用单项信号和目标次级范围均正确。
7. 并发命中、进程重启、journal 重放和 profile revision 变化不会重复发送或漏发。
8. 自动提示节点为本地策略来源且 priority tier 不高于 1；用户层级 0 节点始终优先。
9. 提示词不能批准安装、删除备份、扩大权限、合并、推送或用户体验验收。
10. 工匠缺少依赖时只上报或用已有工具降级，不能自行安装/注册新工具。
11. 工匠产物由不同测试/验收 Agent验证，提交变化或工具 revision 变化使旧验收/兼容性失效。
12. 可复用工作流至少在一个真实夹具中减少重复规划步骤或工具调用，并报告测量方法和局限，不能只作自然语言宣称。

## 4. 界面与用户配置

- 显示三个建议阶段模板，但允许用户创建、命名、复制、排序和删除任意数量的自定义模板。
- 可配置阶段信号、数值阈值、`any/all`、冷却、每阶段提醒次数、目标次级范围、披露动作和 `secondaryArrangementPromptTemplate`。
- 用户可以随时手动披露或关闭自动披露。手动披露不直接创建 Agent，也不绕过任务/权限门禁。
- 次级收到通知时显示命中原因、阶段策略、预期用途和“可选而非已授权/已执行”。
- 主 Agent向用户说明时读取次级摘要，不把工匠的长工作记录注入主对话。

## 5. 执行约束

- 生产变量和函数必须使用完整可读名称；布尔值使用 `is/has/can/should`，时间和字节量明确单位。
- `pn` 每次最多 3 小时；阶段时长不是 `pn`，也不是任务超时或授权有效期。
- 任何删除、文字删减、替换、截断或覆盖必须由工具在变更前自动备份。
- 每个检查点同时更新实现、测试、文档和 `PLAN_STATUS.md`；运行针对性测试、`npm run typecheck`、`npm run lint`。
- T08D 全部完成后运行 `npm run check`、覆盖率和 tarball 隔离安装；没有真实命令和退出码证据不得标记完成。
