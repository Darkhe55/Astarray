## 检查点

### WB-00-01：场景与能力边界

- 状态：pending。
- 工作：选择专家和普通用户都可执行的文本/代码修订场景；定义可编辑格式、往返损失、草稿/发布/撤销和来源契约。
- 验收：能力矩阵和ADR草案明确原生编辑、局部替换与只读范围，不宣称全部格式可无损编辑。
- 前驱：本卡前驱。先通过前驱，再执行本节点。

### WB-00-02：最小内嵌编辑原型

- 状态：pending。
- 工作：懒加载一个文本/代码编辑器；人类草稿自动保存，发布检查点后才形成可回交模型的不可变差异。
- 验收：逐按键不触发模型；编辑来源具体到人类个体；删减/覆盖先由执行层备份，撤销不替代备份。
- 前驱：WB-00-01。先通过前驱，再执行本节点。

### WB-00-03：协同与恢复

- 状态：pending。
- 工作：接入产物revision和Agent变更对比，模拟人类并行修改、编辑器崩溃及重开。
- 验收：人类修改保留，陈旧覆盖拒绝；草稿恢复；模型只接收相关有界差异，预算与模式边界有效。
- 前驱：WB-00-02。先通过前驱，再执行本节点。

### WB-00-04：资源和立项结论

- 状态：pending。
- 工作：测冷启动、首次可编辑、空闲/活动内存、CPU、磁盘、关闭回收和修订总耗时；评估懒加载/休眠效果。
- 验收：提交设备规格、输入规模、原始测量和扩展建议；只在证据支持后提出图片/UI/视频新任务卡。
